# DBot Strategy Collection

This repo contains separate XML strategy files for the four market families you requested:

- `bots/over_under_market.xml` — waits for 3 consecutive ticks before trading Over or Under 3.
- `bots/even_odd_market.xml` — waits for 3 consecutive even or odd digit sequences before trading.
- `bots/rise_fall_market.xml` — waits for 3 consecutive rise or fall ticks before trading.

Rules implemented in all of them:

- fixed stake of `0.35`
- stop after `2` consecutive losses
- wait for a fresh sequence after the stop condition
- track `Tick History`, `Digit History`, and `Consecutive Losses`
- reset the loss counter after a win

Note: these are structured as Deriv DBot-style XML skeletons and are meant to be used as a starting point for final import into the Deriv DBot editor. The exact tick-reading block names may need minor adjustments depending on the DBot version used in your editor.
